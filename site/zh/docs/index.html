文档

安装 Molt、使用 CLI、添加自己的工具，以及更新 Molt 本体。

安装

DMG

下载 Molt-macos.dmg，拖入 Applications，打开即可。通用二进制支持 Apple Silicon 与 Intel，需要 macOS 14+。

一行命令

curl -fsSL https://molt-site-five.vercel.app/install.sh | sh

安装脚本会下载最新 App 和 CLI、校验 SHA-256、安装到 /Applications（或 ~/Applications）与 /usr/local/bin（或 ~/.local/bin），并移除 quarantine 属性。

Homebrew

brew tap nichenqin/molt https://github.com/nichenqin/molt
brew install --cask molt-app
brew install molt

Homebrew 安装的版本用 brew upgrade 更新；Molt 检测到 CLI 由 Homebrew 管理时会提示，而不会自行覆盖。

签名状态。 Developer ID 签名和 Apple 公证已接入发布流水线，但需要 Apple Developer Program 账号，当前公开构建尚未启用。若 macOS 首次拦截，右键 → 打开，或执行 xattr -dr com.apple.quarantine /Applications/Molt.app。

CLI

molt                       # 扫描并列出
molt list --json           # 稳定 JSON
molt list --cached         # 上次快照，不联网
molt list --source npm     # homebrew npm pnpm bun app cli mas custom
molt upgrade --all --yes
molt upgrade cc-switch --dry-run
molt changelog iina --limit 3
molt open sqlite
molt update --check        # 检查 Molt 本体
molt update                # 原子替换 CLI
molt doctor --json
molt cache path|size|clear
molt config path|init|show|edit

molt upgrade 会先显示完整 argv。没有 --yes 时在 TTY 上询问一次，在脚本中拒绝执行。只提供下载页的应用不会被静默安装。

自定义工具

编辑 ~/.config/molt/config.json，支持只写需要的字段：

{
  "disabledSources": ["mas"],
  "customTools": [
    {
      "name": "mytool",
      "path": "/usr/local/bin/mytool",
      "versionArgs": ["--version"],
      "versionRegex": "mytool (\\d+\\.\\d+\\.\\d+)",
      "github": "acme/mytool",
      "upgradeArgs": ["mytool", "self-update"]
    }
  ]
}

upgradeArgs 的第一个元素会被检测到的可执行文件路径替换，其余原样传入。不写则打开发布页。

更新 Molt 本体

Molt 检查静态 feed：https://molt-site-five.vercel.app/latest.json。有新版本时应用顶部会出现更新条；Molt → 检查更新… 打开更新面板。下载的 ZIP 会按 feed 中的 SHA-256 校验，然后由一个很小的 helper 等待 Molt 退出、带回滚地替换 App 包并重启。

CLI 使用同一个 feed：

molt update --check
molt update

Homebrew 用户应使用 brew upgrade molt 和 brew upgrade --cask molt-app。如果 App 运行在不可写目录（例如 quarantine translocation 路径），Molt 会拒绝替换。

安全与限制

  • 无账号、无统计、无常驻进程、不注入 sudo。
  • 升级计划是 argv 数组，包名不会被拼进 shell 字符串。
  • 更新下载必须 HTTPS，并用 feed 中的 SHA-256 校验。
  • 忽略 Sparkle delta 包，使用完整下载。
  • 扫描时设置 HOMEBREW_NO_AUTO_UPDATE=1；想立刻拿最新 formula 元数据需自行 brew update。
  • 应用更新来自 Sparkle feed、Electron Builder app-update.yml（GitHub 或 HTTPS manifest）或显式的 bundle id 目录/配置项；绝不按显示名称猜测。Magpie 使用 com.yetone.magpie 与 yetone/magpie-releases。没有可用更新源的应用会以“未检查”出现在应用来源详情中。

从源码构建

git clone https://github.com/nichenqin/molt.git
cd molt
swift test
make app
make install

需要 Swift 6 与 macOS 14+。App 和 CLI 共用 MoltCore，无常驻进程，无第三方运行时依赖。
